# Feathergrid social media

Pictures of Feathergrid's **approved** social posts, served to Buffer when each post goes out.

- Public on purpose: every picture here is published on LinkedIn, X or Instagram anyway.
- Files are added only by the publisher in feathergrid/feathergrid-social (private), under `posts/<post id>/<content hash>-<name>`, so an address never changes once a post is scheduled.
- Nothing else belongs here: no drafts, no customer data, no keys.
